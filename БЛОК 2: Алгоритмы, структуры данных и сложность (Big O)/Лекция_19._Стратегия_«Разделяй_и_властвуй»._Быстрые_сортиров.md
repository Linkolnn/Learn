# Лекция 19: Стратегия «Разделяй и властвуй». Быстрые сортировки (Merge Sort & QuickSort)

В предыдущих лекциях мы разобрали базовые алгоритмы сортировки со сложностью **O(n²)** (пузырьковую, выбором и вставками). Они просты в реализации и эффективны на малых объемах данных (10–20 элементов), но при росте массива до миллиона элементов требуют порядка миллиона миллиардов операций и становятся неприменимыми на практике.

Сегодня мы совершим совершим качественный скачок в скорости и изучим фундаментальную алгоритмическую парадигму — **«Разделяй и властвуй» (Divide and Conquer)**, а также два мощнейших алгоритма сортировки: **Сортировку слиянием (Merge Sort)** и **Быструю сортировку (QuickSort)**, работающие за время **O(n log n)**.

---

## Подглава 19.1: Парадигма «Разделяй и властвуй» (Divide and Conquer)

Стратегия «Разделяй и властвуй» состоит из трех последовательных шагов:

1. **Разделение (Divide):** Исходная задача разбивается на несколько меньших подзадач того же типа.
2. **Властвование (Conquer):** Подзадачи решаются рекурсивно. Если размер подзадачи достаточно мал (базовый случай), она решается непосредственно.
3. **Комбинирование (Combine):** Решения подзадач объединяются в единое решение исходной задачи.

Почему это дает логарифмический прирост скорости?
При делении массива размера `n` пополам на каждом шаге мы строим дерево рекурсии высотой всего **log₂ n** уровней. Если на каждом уровне мы выполняем суммарно **O(n)** работы, то итоговая сложность составляет **O(n log n)**.

Для массива из **1 000 000 элементов**:
* Алгоритм `O(n²)` делает около **1 000 000 000 000** операций.
* Алгоритм `O(n log n)` делает всего около **20 000 000** операций (в 50 000 раз быстрее!).

## Подглава 19.2: Сортировка слиянием (Merge Sort)

### 1. Идея и принцип работы
Сортировка слиянием — это классический представитель алгоритмов «Разделяй и властвуй».

1. **Разделение:** Массив рекурсивно делится ровно пополам, пока не получатся подмассивы длиной 1 элемент (массив из 1 элемента отсортирован по определению).
2. **Комбинирование (Merge):** Два отсортированных соседних подмассива сливаются в один отсортированный массив большего размера с помощью двух указателей.

### 2. Реализация функции слияния и сортировки на Си

```c
#include <stdio.h>
#include <stdlib.h>

// Вспомогательная функция слияния двух отсортированных подмассивов:
// [left .. mid] и [mid + 1 .. right]
void merge(int *arr, size_t left, size_t mid, size_t right) {
    size_t n1 = mid - left + 1;
    size_t n2 = right - mid;

    // Выделяем временную память под левую и правую половины
    int *L = (int *)malloc(n1 * sizeof(int));
    int *R = (int *)malloc(n2 * sizeof(int));

    if (L == NULL || R == NULL) {
        fprintf(stderr, "Ошибка выделения памяти в merge()
");
        free(L);
        free(R);
        return;
    }

    // Копируем данные во временные массивы
    for (size_t i = 0; i < n1; i++) L[i] = arr[left + i];
    for (size_t j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];

    // Слияние временных массивов обратно в arr[left .. right]
    size_t i = 0; // Индекс в L
    size_t j = 0; // Индекс в R
    size_t k = left; // Индекс в основном массиве

    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) { // <= обеспечивает устойчивость сортировки
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }

    // Дописываем оставшиеся элементы из L (если есть)
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }

    // Дописываем оставшиеся элементы из R (если есть)
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }

    // Освобождаем временную память
    free(L);
    free(R);
}

// Главная рекурсивная функция Merge Sort
void merge_sort(int *arr, size_t left, size_t right) {
    if (left < right) {
        // Вычисляем середину без риска переполнения size_t
        size_t mid = left + (right - left) / 2;

        // Рекурсивно сортируем левую и правую половины
        merge_sort(arr, left, mid);
        merge_sort(arr, mid + 1, right);

        // Сливаем отсортированные половины
        merge(arr, left, mid, right);
    }
}
```

### 3. Оценка сложности и особенности Merge Sort
* **Временная сложность (Time Complexity):**
  * Худший, средний и лучший случаи: **O(n log n)** (гарантированное время при любых данных!).
* **Пространственная сложность (Space Complexity):** **O(n)** — требование дополнительной памяти в куче под временные буферы слияния.
* **Устойчивость (Stability):** **Устойчивая (Stable)** — условие `L[i] <= R[j]` сохраняет исходный порядок одинаковых элементов.

## Подглава 19.3: Быстрая сортировка (QuickSort)

### 1. Идея и принцип работы
Быстрая сортировка (разработанная Чарльзом Хоаром) считается самым эффективным универсальным алгоритмом сортировки в оперативной памяти.

1. **Выбор опорного элемента (Pivot):** Из массива выбирается один элемент — *пивот*.
2. **Разделение (Partition):** Все элементы массива переупорядочиваются так, что элементы меньше опорного перемещаются влево от него, а больше или равные — вправо. Сам опорный элемент занимает свое итоговое окончательное место.
3. **Рекурсия:** Алгоритм рекурсивно применяется к левому и правому подмассивам.

### 2. Схема разбиения Ломуто (Lomuto Partition) и реализация на Си

```c
#include <stdio.h>

// Функция обмена элементов
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// Схема разбиения Ломуто
size_t partition(int *arr, size_t low, size_t high) {
    int pivot = arr[high]; // В качестве pivot берем последний элемент
    size_t i = low; // Индекс границы элементов <= pivot

    for (size_t j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            swap(&arr[i], &arr[j]);
            i++;
        }
    }

    // Ставим pivot на его итоговое место между меньшими и большими элементами
    swap(&arr[i], &arr[high]);
    return i; // Возвращаем индекс опорного элемента
}

// Рекурсивная быстрая сортировка
void quick_sort(int *arr, size_t low, size_t high) {
    if (low < high) {
        size_t p = partition(arr, low, high);

        // Рекурсивно сортируем левую и правую части
        if (p > 0) { // Защита от подкрутки size_t ниже нуля
            quick_sort(arr, low, p - 1);
        }
        quick_sort(arr, p + 1, high);
    }
}
```

### 3. Проблема деградации до O(n²) и выбор опорного элемента
Если на каждом шаге выбирать в качестве опорного элемента крайний (первый или последний), а входной массив **уже отсортирован**, то деление будет происходить крайне неравномерно: `0` элементов слева и `n - 1` справа.

В этом случае высота дерева рекурсии вырастет до **n**, а итоговая сложность деградирует до катастрофических **O(n²)**!

**Способы решения проблемы деградации:**
1. **Случайный выбор опорного элемента (Randomized QuickSort):** Выбирать `pivot` по случайному индексу.
2. **Медиана трех (Median-of-three):** Выбирать медиану из первого, среднего и последнего элементов массива.

### 4. Оценка сложности QuickSort
* **Временная сложность (Time Complexity):**
  * Средний и лучший случаи: **O(n log n)** (на практике в 2–3 раза быстрее Merge Sort благодаря отсутствию выделения памяти и отличной локальности кэша ЦП).
  * Худший случай: **O(n²)** (при неудачном выборе pivot на отсортированных данных).
* **Пространственная сложность (Space Complexity):** **O(log n)** — память требуется только под стек рекурсивных вызовов. Сортировка выполняется *in-place*.
* **Устойчивость (Stability):** **Неустойчивая (Unstable)** — обмены при разбиении могут нарушить порядок равных элементов.

## Подглава 19.4: Сравнительный анализ Merge Sort и QuickSort

| Критерий | Merge Sort | QuickSort |
| :--- | :--- | :--- |
| **Худшее время O(T)** | **O(n log n)** (гарантировано) | **O(n²)** (при плохом pivot) |
| **Среднее время O(T)** | **O(n log n)** | **O(n log n)** (быстрее на практике) |
| **Доп. память O(M)** | **O(n)** (требует буфер в куче) | **O(log n)** (только стек вызовов) |
| **Устойчивость** | **Устойчивый (Stable)** | **Неустойчивый (Unstable)** |
| **Работа с диском/связанными списками** | Идеально (последовательный доступ) | Худший выбор для внешних данных |
| **Локальность кэша ЦП** | Средняя | Высочайшая |

## Подсказки к практическим задачам

* **Подсказка к Задаче 1:** На малых размерах (`N <= 16`) оверхед на рекурсивные вызовы и разбиение в QuickSort выше, чем простая перестановка элементов в Insertion Sort. Поэтому гибридный подход активно применяется в стандартных библиотеках языков программирования.
* **Подсказка к Задаче 2:** Введите счетчик текущей глубины `depth` как аргумент функции `quick_sort(..., int depth)`. При каждом рекурсивном вызове передавайте `depth + 1` и обновляйте глобальный максимум `max_depth = max(max_depth, depth)`.
* **Подсказка к Задаче 3:** Для генерации случайных чисел используйте `<stdlib.h>` и `<time.h>` (`srand(time(NULL))`). Вычисление случайного индекса в отрезке: `size_t rand_idx = low + rand() % (high - low + 1);`.
