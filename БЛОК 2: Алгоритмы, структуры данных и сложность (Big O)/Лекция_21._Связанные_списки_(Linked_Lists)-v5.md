# Лекция 21: Односвязные и двусвязные списки (Singly & Doubly Linked Lists)

В предыдущих лекциях мы детально изучили работу с **непрерывными массивами** в виртуальном адресном пространстве процесса, оценили их сложность по нотации **Big O**, разобрали ключевые алгоритмы сортировки и погрузились в **Динамическое Программирование**.

Массивы — прекрасная структура данных, когда нам требуется быстрый доступ к элементам по индексу за константное время `O(1)`. Однако у массивов есть серьезный недостаток: **вставка или удаление элементов в начало или середину требуют сдвига всех последующих элементов** и занимают `O(n)` времени. Кроме того, расширение динамического массива требует выделения нового цельного блока памяти и копирования всех элементов.

Сегодня мы изучим **первую структуру с несмежным (связным) размещением элементов в памяти** — **Связанные списки (Linked Lists)**.

---

## 💡 Глоссарий ключевых терминов лекции

> 📌 **1. Узел (Node)**
> * **Что это:** Базовый элемент связанного списка. Представляет собой структуру в Куче (Heap), состоящую из хранимых данных (`data`) и одного или нескольких указателей (`next`, `prev`).

> 📌 **2. Указатель на следующий узел (`next`)**
> * **Что это:** Поле внутри структуры узла, содержащее адрес в виртуальной памяти процесса (`0x...`), по которому расположен следующий узел списка. У последнего узла это поле равно `NULL`.

> 📌 **3. Голова (Head) и Хвост (Tail)**
> * **Head (Голова):** Переменная-указатель, хранящая адрес самого первого узла списка. Если `head == NULL`, список пуст.
> * **Tail (Хвост):** Указатель на последний узел списка (`next == NULL`). При отдельном хранении указателя `tail` добавление в конец списка выполняется за константное время `O(1)`.

> 📌 **4. Фиктивный узел (Dummy Node / Sentinel Node)**
> * **Что это:** Вспомогательный узел, временно создаваемый на Стеке (`Node dummy;`) перед выполнением операций построения, вставки или удаления.
> * **Зачем нужен:** Избавляет от громоздких проверок вида `if (head == NULL)` и специальной отдельной обработки изменения головы списка.
> * **Почему на Стеке?** Фиктивный узел нужен только локально внутри функции для упрощения манипуляций с указателями. Он не содержит пользовательских данных и не обязан сохраняться после завершения работы функции, поэтому его выгодно создавать на Стеке без вызовов `malloc` и `free`.

## Подглава 21.1: Сравнение Массивов и Связанных списков в ОЗУ

### Как они располагаются в памяти?

1. **Массив (Array):** Занимает **один непрерывный блок в виртуальном адресном пространстве** процесса.
   * *Плюс:* Зная адрес начала `arr` и размер типа, ЦП моментально высчитывает адрес `arr[i]` за `O(1)` благодаря аппаратной арифметике указателей (`address = base + i * sizeof(type)`).
   * *Плюс:* Отличная **кэш-локальность** (CPU Cache Line): при чтении `arr[0]` процессор автоматически подгружает в быстрый кэш L1/L2 соседние элементы `arr[1]`, `arr[2]`.
   * *Минус:* Вставка в середину/начало требует физического сдвига всех последующих элементов за `O(n)`.

2. **Связанный список (Linked List):** Состоит из отдельных узлов, выделенных через `malloc()` в **произвольных местах Кучи (Heap)**.
   * *Плюс:* Вставка и удаление узла (при наличии прямого указателя на нужную позицию) выполняются за константное время **`O(1)`**: достаточно перенаправить пару указателей.
   * *Важное уточнение по удалению:* В односвязном списке для удаления за `O(1)` нужен указатель на *предшествующий* узел (чтобы перешагнуть через удаляемый). Если дан указатель только на сам удаляемый узел или поиск идет от `head` по значению, удаление потребует `O(n)`. В двусвязном списке благодаря полю `prev` достаточно указателя на сам удаляемый узел.
   * *Плюс:* Список легко растёт и сжимается во время выполнения программы без перевыделения огромных цельных кусков памяти.
   * *Минус:* Доступ по индексу `k` требует последовательного прохода от головы по цепочке указателей за `O(n)`.
   * *Минус:* Плохая кэш-локальность (узлы разбросаны по куче, что приводит к CPU Cache Misses) + **расход памяти на выравнивание и оверхед `malloc`**.

---

### Реальный расход памяти на узел (Alignment & Padding)

Начинающие программисты часто думают, что узел `struct Node { int data; struct Node *next; }` на 64-битной системе занимает `4 + 8 = 12 байт`. **Это ошибочно!**

1. **Выравнивание данных (Data Alignment):** Процессор эффективнее читает 8-байтовые указатели, если их адреса кратны 8. Компилятор добавляет 4 байта паддинга (заполнителя) после `int data`. В итоге сама структура `Node` занимает **16 байт** (4 байта `data` + 4 байта паддинг + 8 байт `next`).
2. **Служебные заголовки `malloc`:** Система управления памятью выделяет перед каждым блоком скрытый заголовок (обычно `8–16 байт`) для хранения размера блока и флагов освобождения.
3. **Итоговый оверхед:** На каждые 4 байта полезной нагрузки (`int data`) приходится **≈20–28 байт накладных расходов**!

### Сводная таблица: Массив vs Связанный список

| Операция | Массив (Array) | Односвязный список (Singly Linked List) | Двусвязный список (Doubly Linked List) |
| :--- | :--- | :--- | :--- |
| **Чтение / Доступ по индексу** | `O(1)` (Константное) | `O(n)` (Проход от `head`) | `O(n)` (Проход от `head` или `tail`) |
| **Вставка в начало (Head)** | `O(n)` (Сдвиг элементов) | `O(1)` | `O(1)` |
| **Вставка в конец (Tail)** | `O(1)` amortized (динам.) | `O(n)` без `tail` / `O(1)` с `tail` | `O(1)` с указателем `tail` |
| **Вставка после известного узла** | `O(n)` (Сдвиг) | `O(1)` | `O(1)` |
| **Удаление из начала** | `O(n)` (Сдвиг) | `O(1)` | `O(1)` |
| **Удаление из конца** | `O(1)` | `O(n)` (нужен поиск пред-последнего) | `O(1)` с указателем `tail` (благодаря `prev` не нужен поиск) |
| **Расход памяти на узел (64-бит)** | 0 байт оверхеда | ≈12 байт + оверхед `malloc` | ≈20 байт + оверхед `malloc` |
| **Кэш-локальность ЦП** | Отличная (Cache friendly) | Плохая (Разрозненный Heap) | Плохая (Разрозненный Heap) |

## Подглава 21.2: Односвязный список (Singly Linked List)

В односвязном списке каждый узел содержит данные и один указатель `next`, направленный на следующий элемент.

```text
[ Head ] ---> [ Data: 10 | Next ] ---> [ Data: 20 | Next ] ---> [ Data: 30 | Next: NULL ]
```

---

### 1. Объявление структуры узла

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;           // Хранимые данные (4 байта)
    struct Node *next;  // Указатель на следующий узел (8 байт в 64-бит)
} Node;
```

---

### 2. Зачем нужен двойной указатель `Node **head`? (Передача по значению адреса переменной)

В языке C **все аргументы передаются исключительно по значению (копированием)**. В Си нет ссылок! Указатель — это обычная числовая переменная, хранящая адрес.

Если передать в функцию обычный указатель `Node *head`, функция получит **локальную копию адреса**. Изменение `head = new_node` внутри функции изменит только эту локальную копию, а переменная `head` в `main()` останется неизменной!

Чтобы изменить значение переменной `head` в `main()`, мы передаём в функцию **по значению адрес самой переменной `head`** (то есть `Node **head`). Через разыменование `*head` функция работает напрямую с исходной переменной `head` из `main()`.

```text
ОШИБОЧНО (Передача Node *head по значению):
main():       head_var [0x1000] ──> [Node A]
                   │ (копирование адреса)
                   ▼
function():   head_copy [0x1000] ──> [Node B] (изменена только копия!)

ПРАВИЛЬНО (передаём по значению адрес самой переменной head):
main():       head_var [0x1000] ──> [Node A]
                   ▲
                   │ (хранит адрес переменной head_var)
function():   head_ptr [0x7FFF...] ──> через *head_ptr изменяет напрямую head_var в main()!
```

---

### 3. Создание узла и Вставка в начало (`insert_at_head`) — `O(1)`

```c
// Функция создания узла в Куче
Node* create_node(int value) {
    Node *new_node = malloc(sizeof(Node)); // В Си приведение (Node*) не требуется
    if (new_node == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память под узел!\n");
        return NULL;
    }
    new_node->data = value;
    new_node->next = NULL;
    return new_node;
}

// Вставка в начало за O(1)
bool insert_at_head(Node **head, int value) {
    if (head == NULL) return false;

    Node *new_node = create_node(value);
    if (new_node == NULL) return false;

    new_node->next = *head;
    *head = new_node;
    return true;
}
```

#### Наглядная схема вставки в начало:
```text
Шаг 1: Создаём new_node [ 5 | NULL ]
Шаг 2: new_node->next = *head

        new_node [ 5 | next ]
                        │
                        ▼
          head ───────> [ 10 | next ] ───> [ 20 | NULL ]

Шаг 3: *head = new_node

          head ───────> [ 5 | next ] ───> [ 10 | next ] ───> [ 20 | NULL ]
```

---

### 4. Вставка после известного узла (`insert_after`) — `O(1)`

Эта операция демонстрирует главное преимущество списка: имея указатель на произвольный узел `prev_node`, вставка нового элемента выполняется за константное время `O(1)` без сдвига данных!

```c
bool insert_after(Node *prev_node, int value) {
    if (prev_node == NULL) {
        fprintf(stderr, "Ошибка: предшествующий узел не может быть NULL!\n");
        return false;
    }

    Node *new_node = create_node(value);
    if (new_node == NULL) return false;

    new_node->next = prev_node->next;
    prev_node->next = new_node;
    return true;
}
```

#### Наглядная схема вставки в середину (`insert_after`):
```text
Было:    [ Node A ] ─────────────────────────> [ Node B ]

         new_node [ New Node ]
                     │
                     ▼
Шаг 1:   new_node->next = prev_node->next  (указывает на Node B)

Шаг 2:   prev_node->next = new_node

Стало:   [ Node A ] ───> [ New Node ] ───> [ Node B ]
```

---

### 5. Добавление в конец списка с поддержкой `tail` — `O(1)` vs `O(n)`

```c
// Без указателя tail: требует прохода всего списка за O(n)
bool insert_at_tail(Node **head, int value) {
    if (head == NULL) return false;

    Node *new_node = create_node(value);
    if (new_node == NULL) return false;

    if (*head == NULL) {
        *head = new_node;
        return true;
    }

    Node *current = *head;
    while (current->next != NULL) {
        current = current->next;
    }
    current->next = new_node;
    return true;
}

// С поддержкой указателя tail: выполнение за O(1)
bool insert_at_tail_fast(Node **head, Node **tail, int value) {
    if (head == NULL || tail == NULL) return false;

    Node *new_node = create_node(value);
    if (new_node == NULL) return false;

    if (*head == NULL) {
        *head = new_node;
        *tail = new_node;
        return true;
    }

    (*tail)->next = new_node;
    *tail = new_node;
    return true;
}
```

> ⚠️ **Важное предупреждение о `tail`:**  
> Если в вашей структуре данных используется отдельный указатель `tail`, при удалении последнего узла списка его необходимо обязательно обновлять, иначе `tail` превратится в **«висячий указатель» (dangling pointer)** на освобождённую память!

### 6. Использование Фиктивного узла (Dummy Node) в коде

Продемонстрируем силу фиктивного узла на примере функции удаления первого вхождения значения.  
Без dummy node нам пришлось бы писать отдельное ветвление `if ((*head)->data == value)` для обработки изменения головы.  

С фиктивным узлом код становится единым для всех элементов:

```c
bool delete_node_with_dummy(Node **head, int value) {
    if (head == NULL) return false; // Защита от неверного двойного указателя

    // Dummy node на Стеке (не требует malloc и free!)
    Node dummy;
    dummy.next = *head;

    Node *current = &dummy;

    // Ищем узел, ПРЕДШЕСТВУЮЩИЙ удаляемому
    // Заметьте: мы НЕ проверяем (*head == NULL)! Если список пуст,
    // dummy.next равен NULL, цикл while сразу не выполнится, и функция естественно вернёт false.
    // Пустой список обрабатывается автоматически без дополнительных if!
    while (current->next != NULL && current->next->data != value) {
        current = current->next;
    }

    if (current->next == NULL) {
        return false; // Элемент не найден
    }

    // Удаляем узел
    Node *node_to_delete = current->next;
    current->next = node_to_delete->next;
    free(node_to_delete);

    // Обновляем реальную голову в main
    *head = dummy.next;
    return true;
}
```

#### Схема удаления узла:
```text
                 current            node_to_delete
                   │                     │
                   ▼                     ▼
Было:   ... ──> [ 10 | next ] ────────> [ 20 | next ] ────────> [ 30 | next ]

Действие: current->next = node_to_delete->next

Стало:  ... ──> [ 10 | next ] ────────────────────────────────> [ 30 | next ]
                                       [ 20 | free() ]
```

### 7. Обход, печать и очистка памяти списка

```c
// Печать элементов списка
void print_list(const Node *head) {
    const Node *current = head;
    printf("List: ");
    while (current != NULL) {
        printf("[%d] -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

// Освобождение памяти (защита от Memory Leaks)
void free_list(Node **head) {
    if (head == NULL) return;
    Node *current = *head;
    Node *next_node = NULL;

    while (current != NULL) {
        next_node = current->next; // Запоминаем следующий узел
        free(current);             // Освобождаем текущий
        current = next_node;       // Переходим дальше
    }

    *head = NULL;
}
```

> ⚠️ **Уточнение по утечкам памяти (Memory Leaks):**  
> При выходе из программы современная ОС (Linux, Windows, macOS) автоматически забирает всю память процесса. Однако освобождать память вручную через `free_list()` **критически необходимо** по двум причинам:  
> 1. В долгоживущих программах (веб-серверы, демоны, игры) блоки памяти, не освобождённые через `free()`, приводят к постепенному исчерпанию ОЗУ сервера.  
> 2. Инструменты динамического анализа (Valgrind, AddressSanitizer) справедливо помечают не освобождённые через `free()` блоки как утечки.

### 8. Разворот односвязного списка (Reverse List) — `O(n)` времени, `O(1)` памяти

```c
void reverse_list(Node **head) {
    if (head == NULL || *head == NULL) return;

    Node *prev = NULL;
    Node *current = *head;
    Node *next = NULL;

    while (current != NULL) {
        next = current->next; // 1. Запоминаем следующий узел
        current->next = prev; // 2. Разворачиваем стрелку назад
        
        prev = current;       // 3. Сдвигаем prev вправо
        current = next;       // 4. Сдвигаем current вправо
    }

    *head = prev; // Бывший хвост становится новой головой
}
```

#### Пошаговая схема разворота указателей:
```text
Исходное состояние:
  head ───────> [ 10 | next ] ───> [ 20 | next ] ───> [ 30 | NULL ]
 prev = NULL, current = 10, next = NULL

Итерация 1:
NULL <─── [ 10 | next ]       [ 20 | next ] ───> [ 30 | NULL ]
  ▲            ▲                   ▲
  │            │                   │
 prev       current              next

Итерация 2:
NULL <─── [ 10 | next ] <─── [ 20 | next ]       [ 30 | NULL ]
               ▲                   ▲                   ▲
               │                   │                   │
              prev              current              next

Итерация 3:
NULL <─── [ 10 | next ] <─── [ 20 | next ] <─── [ 30 | next ]       NULL
                                    ▲                   ▲            ▲
                                    │                   │            │
                                   prev              current        next

Итог (*head = prev):
  head ───────────────────────────────────────────────┘
```

## Подглава 21.3: Двусвязный список (Doubly Linked List)

В двусвязном списке каждый узел содержит два указателя: `next` (на следующий узел) и `prev` (на предыдущий узел).

```text
NULL <--- [ Prev | Data: 10 | Next ] <---> [ Prev | Data: 20 | Next ] <---> [ Prev | Data: 30 | Next ] ---> NULL
```

### Преимущества Двусвязного списка:
1. Возможность обходить список **в обоих направлениях** (вперед по `next` и назад по `prev`).
2. **Удаление узла за `O(1)`**, если у нас есть прямой указатель на этот узел (не нужно искать предшествующий узел проходом от головы, так как он доступен по `target->prev`).
3. Вставка в начало и в конец за **`O(1)`** при наличии указателей `head` и `tail`.

### Объявление и ключевые операции на Си

```c
typedef struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
} DNode;

// Вставка в начало двусвязного списка за O(1)
bool insert_dnode_head(DNode **head, int value) {
    if (head == NULL) return false;

    DNode *new_node = malloc(sizeof(DNode));
    if (new_node == NULL) return false;

    new_node->data = value;
    new_node->prev = NULL;
    new_node->next = *head;

    if (*head != NULL) {
        (*head)->prev = new_node;
    }

    *head = new_node;
    return true;
}

// Удаление узла target за O(1) по прямому указателю
// Примечание: предполагается, что target действительно принадлежит данному списку.
void delete_dnode(DNode **head, DNode *target) {
    if (head == NULL || *head == NULL || target == NULL) return;

    // Если удаляем голову
    if (*head == target) {
        *head = target->next;
    }

    // Корректируем указатель next у предыдущего узла
    if (target->prev != NULL) {
        target->prev->next = target->next;
    }

    // Корректируем указатель prev у следующего узла
    if (target->next != NULL) {
        target->next->prev = target->prev;
    }

    free(target);
}
```

## Подглава 21.4: Паттерн «Быстрый и Медленный указатель» (Fast & Slow Pointers)

Паттерн основан на движении двух указателей с разной скоростью:
* **Slow (Черепаха):** двигается на 1 шаг за итерацию (`slow = slow->next`).
* **Fast (Заяц):** двигается на 2 шага за итерацию (`fast = fast->next->next`).

### Где применимо?
1. **Поиск середины списка за один проход (`O(n)` времени, `O(1)` памяти):** Когда `fast` дойдет до конца списка, `slow` окажется ровно посередине!
   *Для списка чётной длины (например, `1 -> 2 -> 3 -> 4`) `slow` остановится на **втором из двух центральных элементов (`3`)**.*
2. **Обнаружение зацикливания списка (Алгоритм Флойда / Cycle Detection):** Если в односвязном списке есть замкнутый цикл (указатель `next` некоторого узла ведет назад), то быстрый указатель (Заяц), двигающийся в 2 раза быстрее, рано или поздно зайдёт в цикл и догонит медленный указатель (Черепаху). Когда они окажутся в одном и том же узле (`slow == fast`), зацикливание подтверждено.

```c
Node* find_middle(Node *head) {
    if (head == NULL) return NULL;

    Node *slow = head;
    Node *fast = head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;       // 1 шаг
        fast = fast->next->next; // 2 шага
    }

    return slow;
}
```

## Подглава 21.5: Полный рабочий пример приложения на Си

Ниже приведен готовый компилируемый код, объединяющий все изученные функции в один сценарий:

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* create_node(int value) {
    Node *new_node = malloc(sizeof(Node));
    if (new_node == NULL) return NULL;
    new_node->data = value;
    new_node->next = NULL;
    return new_node;
}

bool insert_at_head(Node **head, int value) {
    if (head == NULL) return false;
    Node *new_node = create_node(value);
    if (new_node == NULL) return false;
    new_node->next = *head;
    *head = new_node;
    return true;
}

bool insert_at_tail(Node **head, int value) {
    if (head == NULL) return false;
    Node *new_node = create_node(value);
    if (new_node == NULL) return false;
    if (*head == NULL) {
        *head = new_node;
        return true;
    }
    Node *current = *head;
    while (current->next != NULL) {
        current = current->next;
    }
    current->next = new_node;
    return true;
}

bool insert_after(Node *prev_node, int value) {
    if (prev_node == NULL) return false;
    Node *new_node = create_node(value);
    if (new_node == NULL) return false;
    new_node->next = prev_node->next;
    prev_node->next = new_node;
    return true;
}

bool delete_node_with_dummy(Node **head, int value) {
    if (head == NULL) return false;
    Node dummy;
    dummy.next = *head;
    Node *current = &dummy;
    while (current->next != NULL && current->next->data != value) {
        current = current->next;
    }
    if (current->next == NULL) return false;
    Node *node_to_delete = current->next;
    current->next = node_to_delete->next;
    free(node_to_delete);
    *head = dummy.next;
    return true;
}

void reverse_list(Node **head) {
    if (head == NULL || *head == NULL) return;
    Node *prev = NULL, *current = *head, *next = NULL;
    while (current != NULL) {
        next = current->next;
        current->next = prev;
        prev = current;
        current = next;
    }
    *head = prev;
}

Node* find_middle(Node *head) {
    if (head == NULL) return NULL;
    Node *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

void print_list(const Node *head) {
    const Node *current = head;
    printf("List: ");
    while (current != NULL) {
        printf("[%d] -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

void free_list(Node **head) {
    if (head == NULL) return;
    Node *current = *head;
    while (current != NULL) {
        Node *next_node = current->next;
        free(current);
        current = next_node;
    }
    *head = NULL;
}

int main(void) {
    Node *head = NULL;

    // 1. Наполнение списка
    insert_at_head(&head, 20);
    insert_at_head(&head, 10);
    insert_at_tail(&head, 40); // Список: [10] -> [20] -> [40] -> NULL
    print_list(head);

    // 2. Вставка за первым узлом
    insert_after(head, 15);    // Список: [10] -> [15] -> [20] -> [40] -> NULL
    print_list(head);

    // 3. Удаление узла с помощью dummy node
    delete_node_with_dummy(&head, 20); // Список: [10] -> [15] -> [40] -> NULL
    print_list(head);

    // 4. Разворот списка
    reverse_list(&head);       // Список: [40] -> [15] -> [10] -> NULL
    print_list(head);

    // 5. Поиск середины
    Node *mid = find_middle(head);
    if (mid != NULL) {
        printf("Серединный элемент: %d\n", mid->data);
    }

    // 6. Полная очистка памяти
    free_list(&head);
    return 0;
}
```

## Подсказки к практическим задачам

* **Подсказка к Задаче 1:** Запустите `slow = head` и `fast = head`. Пока `fast != NULL && fast->next != NULL`, двигайте `slow = slow->next`, а `fast = fast->next->next`.
* **Подсказка к Задаче 2:** Запустите `slow = head` и `fast = head`. На каждой итерации цикла сдвигайте `slow = slow->next` и `fast = fast->next->next`. **Сравнивайте `slow == fast` только ПОСЛЕ перемещения указателей** (так как в самом начале они оба указывают на `head`).
