## 🎯 ГЛАВНЫЕ ПРИНЦИПЫ ОБУЧЕНИЯ
1. **Самостоятельное написание кода (Без ИИ):** Весь код пишется руками, строчка за строчкой. Ошибки компиляции, баги и типы анализируются самостоятельно.
2. **Спуск к «железу» и фундаментам:** Каждая технология объясняется с точки зрения памяти, работы процессора, сетевых пакетов или архитектуры движков (V8, Libuv, Go GMP).
3. **Соответствие требованиями работодателей (hh.ru / Хабр Карьера):** Темы охватывают все реальные вопросы с собеседований и нюансы продакшена.

### 📋 ПОДРОБНОЕ ОПИСАНИЕ ЭТАПОВ ПРАКТИКИ:

#### 🔹 Этап 0: Системный C-Чат & GitFlow (Отдельная фундаментальная стадия)
* **Назначение:** Самостоятельная академическая стадия для полного прохождения курса с самого низкого уровня (для будущих учащихся).
* **Стек:** C (`sys/socket.h`, `pthread`), GitFlow (`main`, `develop`, `feature/*`), `Makefile`, GitHub Actions CI/CD.
* **Результат:** Системный консольный многопользовательский чат на сокетах C с автоматической сборкой в CI.

#### 🔹 Этап 1: Todo App на Vanilla JS + Повтор GitFlow & CI/CD (Быстрый перескок на Веб!)
* **Назначение:** Прямой старт в веб-разработку без потери инженерной дисциплины!
* **Повтор GitFlow & CI/CD:** Чтобы сразу работать по стандартам коммерческой разработки, на этом этапе с нуля воспроизводятся настройки GitFlow (фича-ветки) и создается `.github/workflows/ci.yml` для автоматической проверки кода при пуше на GitHub.
* **Стек & Функционал:**
  * Интерактивное приложение управления задачами: категории, приоритеты, теги, поиск, сортировка.
  * Чистый **Vanilla JS (ES6+)**, DOM API, Event Delegation.
  * Вёрстка и стилизация на **SCSS** (пакет `sass` ставится через npm, компиляция и режим `--watch` настраиваются npm-скриптами в `package.json`).
  * Инструменты: `package.json` и `package-lock.json` хранятся в репозитории, `node_modules` — в `.gitignore`; в CI — `actions/setup-node`, `npm ci` и сборка SCSS в CSS (`npm run build:css`) перед деплоем.
  * Без бэкенда: работа с браузерными хранилищами `localStorage` и `IndexedDB`.
  * Автоматический деплой на GitHub Pages / Vercel через GitHub Actions.

#### 🔹 Этап 2: Перевод Todo App на TypeScript & Архитектура
* **Назначение:** Отработка строгой типизации и чистой архитектуры на знакомом проекте.
* **Стек & Функционал:**
  * Полный рефакторинг Todo App на **TypeScript** + сборщик **Vite** (проект создаётся и запускается через npm: `npm create vite@latest`, `npm run dev`, `npm run build`).
  * Стилизация на **SCSS** (Vite поддерживает SCSS без правки конфига, достаточно установить пакет: `npm i -D sass`).
  * Паттерн «Репозиторий» (`ITodoRepository`), строгое описание типов (`TodoItem`, `PriorityEnum`), Generics для адаптеров хранилищ (`LocalStorageAdapter`, `IndexedDBAdapter`).
  * Настройка CI/CD (`actions/setup-node`, `npm ci`) на обязательную проверку типов `tsc --noEmit` перед слиянием PR.

#### 🔹 Этап 3: Frontend "Room Chat App" на Vue 3 + Nuxt 3 (Основной стек)
* **Назначение:** Создание полноценного веб-чата с комнатами и ссылками-приглашениями.
* **Стек & Функционал:**
  * **Vue 3** (Composition API, `<script setup>`), **Nuxt 3** (SSR, файловый роутинг `pages/room/[id].vue`, `pages/invite/[code].vue`), **Pinia** (управление состоянием комнат и сообщений), **SCSS** (модульная вёрстка компонентов, `<style lang="scss" scoped>`).
  * Доступ в комнаты по уникальным ссылкам-приглашениям.
  * Работа фронтенд-части: эмуляция получения сообщений, локальное хранение в `IndexedDB` и межвкладочная синхронизация через `BroadcastChannel API`.

#### 🔹 Этап 4: Альтернативный Frontend "Room Chat App" на React 18+ + Next.js (Второй стек)
* **Назначение:** Создание аналогичного фронтенда для сравнения двух ведущих фреймворков рынка.
* **Стек & Функционал:**
  * **React 18+**, **Next.js 14+ (App Router)** (`app/room/[id]/page.tsx`), **Zustand**, **TanStack Query (React Query)**, **SCSS / CSS Modules**.

#### 🔹 Этап 5: Backend "Room Chat API" на Node.js / NestJS + PostgreSQL
* **Назначение:** Разработка бэкенд-сервера и подключение к нему обоих фронтендов (Vue и React).
* **Стек & Функционал:**
  * **Node.js** (Express / NestJS), **PostgreSQL** + **Prisma ORM**.
  * Real-time обход через **WebSockets (Socket.io)**.
  * Безопасность: JWT (Access + Refresh токены в `HttpOnly`, `Secure` cookies), `bcrypt`, CORS, Rate Limiting.
  * Интеграция: Подключение фронтендов на Nuxt 3 и Next.js к единому реальному API.

#### 🔹 Этап 6: Highload Backend "Room Chat Engine" на Go (Golang) + gRPC
* **Назначение:** Масштабирование чата под высокую нагрузку (10 000+ одновременных сокетов).
* **Стек & Функционал:**
  * **Go (Golang)**: Горутины, Каналы, фреймворки **Gin / Fiber**.
  * **Redis Pub/Sub**: Межсервисный брокер для рассылки сообщений между нодами.
  * **gRPC & Protobuf**: Выделенный микросервис авторизации и управления комнатами.

#### 🔹 Этап 7: Fullstack Multi-Container Deployment (Деплой в Продакшен)
* **Назначение:** Финальный запуск всей системы на реальном сервере.
* **Стек & Функционал:**
  * **Docker Compose**: Оркестрация контейнеров (Nuxt/Next + Node.js API + Go WebSocket Engine + PostgreSQL + Redis + Nginx Reverse Proxy).
  * Деплой на Linux VPS, настройка Nginx, выпуск SSL-сертификатов Let's Encrypt (`certbot`), CI/CD деплой по пушу в `main`.
