# Лекция 3: Логические вентили, условия и булева алгебра

## Подглава 3.1: Булева алгебра и логические вентили — математика в кремнии

До сих пор мы рассматривали компьютер как устройство, которое умеет хранить числа в памяти и выполнять с ними простые арифметические операции. Но как процессор принимает решения? Как он понимает, что одна инструкция должна выполниться, а другая — нет?

В основе любого логического выбора компьютера лежит **булева алгебра** (математическая логика). В отличие от обычной алгебры, где переменные могут принимать любые числовые значения, в булевой алгебре переменные могут находиться только в одном из двух состояний:
* **Истина (True)** — в компьютере представляется как двоичная единица `1` (высокое электрическое напряжение на транзисторе, например, 3.3 Вольта).
* **Ложь (False)** — представляется как двоичный ноль `0` (низкое электрическое напряжение или его отсутствие, 0 Вольт).

### Базовые логические операции и вентили
На физическом уровне внутри процессора установлены миллионы крошечных переключателей — транзисторов. Они объединяются в простейшие схемы, которые называются **логическими вентилями**. Каждый вентиль принимает на вход электрические сигналы (0 или 1), совершает над ними логическую операцию и выдает один итоговый сигнал.

Рассмотрим четыре фундаментальные логические операции:

1. **Отрицание: НЕ (NOT)**
   * **Математический смысл:** Меняет значение на противоположное. Если на входе была Истина, на выходе будет Ложь, и наоборот.
   * **Таблица истинности:**
     * NOT 0 = 1
     * NOT 1 = 0

2. **Конъюнкция: И (AND)**
   * **Математический смысл:** Итоговый результат будет Истиной **только в том случае, если оба входящих сигнала равны Истине**. Если хотя бы один вход равен нулю, выход тоже будет нулевым.
   * **Таблица истинности:**
     * 0 AND 0 = 0
     * 0 AND 1 = 0
     * 1 AND 0 = 0
     * 1 AND 1 = 1

3. **Дизъюнкция: ИЛИ (OR)**
   * **Математический смысл:** Итоговый результат будет Истиной, **если хотя бы один из входящих сигналов равен Истине**. Выход будет ложным только в том случае, если на всех входах нули.
   * **Таблица истинности:**
     * 0 OR 0 = 0
     * 0 OR 1 = 1
     * 1 OR 0 = 1
     * 1 OR 1 = 1

4. **Исключающее ИЛИ: XOR**
   * **Математический смысл:** Результат равен Истине **только тогда, когда входящие сигналы разные** (один равен 1, а другой 0). Если сигналы одинаковые (оба 0 или оба 1), на выходе будет Ложь.
   * **Таблица истинности:**
     * 0 XOR 0 = 0
     * 0 XOR 1 = 1
     * 1 XOR 0 = 1
     * 1 XOR 1 = 0

### Законы де Моргана
В программировании очень часто приходится упрощать сложные логические проверки. Для этого математики Огастес де Морган и Джордж Буль сформулировали правила, позволяющие преобразовывать отрицания логических связок.

Простыми словами законы де Моргана звучат так:
1. **Отрицание операции "И" эквивалентно операции "ИЛИ" от отрицаний:**  
   *Выражение "Неверно, что на улице тепло И идет дождь" означает то же самое, что "На улице НЕ тепло ИЛИ НЕ идет дождь".*
   * Математически: **NOT (A AND B) = (NOT A) OR (NOT B)**
2. **Отрицание операции "ИЛИ" эквивалентно операции "И" от отрицаний:**  
   *Выражение "Неверно, что я куплю чай ИЛИ кофе" означает то же самое, что "Я НЕ куплю чай И НЕ куплю кофе".*
   * Математически: **NOT (A OR B) = (NOT A) AND (NOT B)**

Эти законы помогают программистам переписывать громоздкие проверки условий в коде так, чтобы они выполнялись быстрее и читались проще.

## Подглава 3.2: Условия в Си — оператор if-else

Чтобы программа на Си могла ветвиться в зависимости от данных, используется оператор **`if`** (если). 

### Синтаксис оператора if
Общая структура условного оператора выглядит следующим образом:

```c
if (условие) {
    // Этот блок кода выполнится, только если условие истинно (не равно нулю)
}
```

В языке Си **любое ненулевое число считается Истиной**, а **ровно ноль считается Ложью**. Это значит, что если в круглых скобках после `if` получается число `5`, то условие считается выполненным.

### Использование else
Если нам нужно выполнить один блок кода при истинности условия, а другой — при его ложности, мы добавляем блок **`else`** (иначе):

```c
#include <stdio.h>

int main() {
    int temperature = 15;

    if (temperature > 20) {
        printf("На улице тепло!\n");
    } else {
        printf("На улице прохладно.\n");
    }

    return 0;
}
```

### Цепочки условий: else if
Когда вариантов развития событий больше двух, мы можем объединять условия в цепочку с помощью **`else if`**:

```c
#include <stdio.h>

int main() {
    int score = 85;

    if (score >= 90) {
        printf("Ваша оценка: Отлично\n");
    } else if (score >= 75) {
        printf("Ваша оценка: Хорошо\n");
    } else if (score >= 60) {
        printf("Ваша оценка: Удовлетворительно\n");
    } else {
        printf("Тест не сдан.\n");
    }

    return 0;
}
```
**Важное правило работы цепочки:** Как только компьютер натыкается на первое истинное условие в цепочке, он выполняет соответствующий блок кода, а всю оставшуюся часть цепочки (все последующие `else if` и итоговый `else`) просто пропускает, даже не пытаясь их проверять.

## Подглава 3.3: Операторы сравнения и логические связки

Внутри круглых скобок оператора `if` мы пишем выражения. Чаще всего они строятся с помощью операторов сравнения и логических операторов.

### Операторы сравнения в Си
Чтобы сравнить две величины, используются следующие операторы:
* **`==`** — проверка на равенство. **Обратите внимание:** оператор равенства состоит из двух знаков "равно". Одиночный знак `=` — это оператор присваивания, который записывает значение в переменную! Если вы случайно напишете `if (a = 5)`, Си запишет `5` в переменную `a`, интерпретирует результат как Истину и всегда выполнит блок кода. Это одна из самых частых и коварных ошибок новичков.
* **`!=`** — проверка на неравенство (не равно).
* **`<`** — меньше.
* **`>`** — больше.
* **`<=`** — меньше или равно.
* **`>=`** — больше или равно.

Пример использования:
```c
int age = 18;
if (age >= 18) {
    printf("Доступ разрешен.\n");
}
```

### Логические операторы Си
Для объединения нескольких проверок в одно условие используются логические операторы, которые полностью соответствуют вентилям булевой алгебры:

1. **`&&`** — логическое **И (AND)**. Условие истинно только тогда, когда истинны обе части выражения.
   ```c
   int age = 20;
   int money = 100;
   if (age >= 18 && money >= 50) {
       printf("Вы можете купить билет.\n");
   }
   ```
2. **`||`** — логическое **ИЛИ (OR)**. Условие истинно, если истинна хотя бы одна из частей выражения.
   ```c
   int has_ticket = 0;
   int has_vip_pass = 1;
   if (has_ticket == 1 || has_vip_pass == 1) {
       printf("Проходите в зал.\n");
   }
   ```
3. **`!`** — логическое **НЕ (NOT)**. Переворачивает значение выражения.
   ```c
   int is_broken = 0;
   if (!is_broken) { // читается как "если НЕ сломано"
       printf("Устройство работает исправно.\n");
   }
   ```

### Оптимизация вычислений (Short-circuit evaluation)
Операторы `&&` and `||` в языке Си работают по принципу так называемого **быстрого (ленивого) вычисления**:
* Если при проверке выражения с оператором `&&` левая часть оказалась ложной (`0`), Си **даже не будет вычислять и проверять правую часть**, так как все выражение гарантированно будет ложным.
* Если при проверке выражения с оператором `||` левая часть оказалась истинной (`1`), Си **сразу прекратит проверку**, так как выражение гарантированно будет истинным.

Это экономит драгоценное время процессора при работе программы.

## Практические задачи

### Задача 1: Анализатор температуры процессора
Напишите программу на Си, которая помогает отслеживать состояние процессора:
1. Объявите целочисленную переменную `temperature` и присвойте ей любое значение (например, 72).
2. Программа должна проверить значение переменной и вывести предупреждение на экран:
   * Если температура строго меньше 0: вывести "Критическое состояние: Замерзание!".
   * Если температура от 0 до 55 включительно: вывести "Режим работы: Нормальный".
   * Если температура от 56 до 80 включительно: вывести "Режим работы: Повышенная нагрузка".
   * Если температура строго больше 80: вывести "Критическое состояние: Перегрев!".

### Задача 2: Двухфакторная авторизация
Напишите симуляцию проверки системы доступа:
1. Объявите две переменные: `int entered_pin = 4455;` (введенный пин-код) и `char entered_symbol = 'Y';` (введенный символ подтверждения).
2. Напишите условие, которое выведет "Доступ успешно предоставлен!", если одновременно соблюдаются два условия: пин-код равен `4455`, а символ равен `'Y'`.
3. Во всех остальных случаях программа должна вывести "Ошибка авторизации: неверный код или символ!".

### Задача 3: Теоретическая проверка (устно)
Упростите логическое выражение, используя законы де Моргана, и запишите итоговый сокращенный вид (используя синтаксис Си с операторами `!`, `&&`, `||`):

`! ( (temperature < 0) || (is_broken == 1) )`

## Подсказки к задачам

* **Подсказка к задаче 1:** Используйте конструкцию `if - else if - else`. Для проверки диапазонов объединяйте два сравнения с помощью оператора логического И (`&&`). Например, проверка диапазона от 10 до 20 включительно выглядит как: `if (temperature >= 10 && temperature <= 20)`.
* **Подсказка к задаче 2:** Внимательно следите за операторами сравнения. Напоминаем, что для проверки равенства чисел и символов в Си используется оператор `==`, а не `=`. Для объединения двух условий используйте оператор `&&`.
* **Подсказка к задаче 3:** Вспомните второй закон де Моргана: отрицание от ИЛИ превращается в И от отрицаний. Примените оператор отрицания `!` к каждому из внутренних выражений в скобках по отдельности, заменив оператор `||` на `&&`.
