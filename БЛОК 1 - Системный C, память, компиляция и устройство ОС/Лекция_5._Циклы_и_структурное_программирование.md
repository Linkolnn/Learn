# Лекция 5: Циклы и структурное программирование

## Подглава 5.1: Итеративная стратегия и сила повторений

Компьютеры превосходят людей в двух вещах: они могут хранить гигантские объемы данных и могут выполнять простейшие операции с невероятной скоростью. Если человеку поручить миллион раз сложить два числа, он совершит массу ошибок, устанет и потратит на это недели. Центральный процессор (ЦП) сделает это за доли секунды, даже не «заметив» нагрузки.

Повторение последовательности действий называется **итерацией**. В программировании итеративная стратегия — это мощнейший инструмент. Вместо того чтобы писать один и тот же код вручную много раз (что приводит к раздуванию файла программы и куче ошибок), мы пишем инструкцию один раз и приказываем процессору выполнять её по кругу до тех пор, пока не будет достигнута определенная цель.

## Подглава 5.2: Революция Эдсгера Дейкстры и структурное программирование

На заре компьютерной эры программисты писали код на низком уровне (в машинных кодах или на ассемблере). Чтобы заставить программу повторить блок кода или обойти ветвление, использовались прямые команды перехода — аналог команды `goto` (перейти на строку X) или ассемблерного `JUMP`.

Это приводило к созданию так называемого **«спагетти-кода»**. Представьте программу, в которой нити управления запутаны, как тарелка спагетти: выполнение прыгает с 10-й строки на 50-ю, оттуда возвращается на 20-ю, затем идет на 100-ю и так далее. Отладка, чтение и модификация такого кода были сущим кошмаром — программисты сами переставали понимать, как работает их собственное детище.

В 1968 году выдающийся ученый в области компьютерных наук **Эдсгер Дейкстра** опубликовал легендарное письмо «О вреде оператора Go To» (Go To Statement Considered Harmful). Это письмо положило начало революции **структурного программирования**.

Дейкстра и его коллеги математически доказали теорему о структурировании: **любую сколь угодно сложную программу можно написать без использования безусловных переходов (goto), используя лишь три базовые управляющие конструкции**:
1. **Следование (Sequencing)** — последовательное выполнение команд сверху вниз (шаг за шагом).
2. **Ветвление / Выбор (Selection)** — выполнение того или иного блока кода в зависимости от условия (наш оператор `if-else` из Лекции 3).
3. **Повторение / Цикл (Iteration)** — многократное выполнение блока кода, пока условие истинно.

Сегодня структурное программирование является абсолютным стандартом. Современные высокоуровневые циклы в Си (`while` и `for`) — это безопасные, упорядоченные конструкции, которые компилятор сам превращает в аккуратные низкоуровневые переходы на уровне машинного кода, оберегая разработчика от «спагетти».

## Подглава 5.3: Цикл while — повторение по условию

Цикл `while` (в переводе с английского — «пока») используется в тех случаях, когда мы не знаем заранее, сколько именно раз нам придется повторить действие, но у нас есть четкое условие, при котором повторение должно продолжаться.

### Синтаксис цикла while:
```c
while (условие) {
    // Тело цикла — инструкции, которые будут повторяться
}
```

### Как это работает под капотом (на уровне процессора):
1. Процессор доходит до начала цикла и проверяет **условие**.
2. Если условие возвращает **истину** (любое число, не равное нулю), процессор входит в тело цикла и поочередно выполняет все инструкции внутри фигурных скобок.
3. Дойдя до закрывающей фигурной скобки `}`, счетчик команд (регистр PC) процессора физически **прыгает обратно** на адрес начала цикла, где снова проверяется условие.
4. Если условие на очередном шаге возвращает **ложь** (число ноль), процессор игнорирует тело цикла, перепрыгивает его и начинает выполнять команды, идущие сразу после закрывающей фигурной скобки цикла.

### Пример кода: счетчик до пяти
```c
#include <stdio.h>

int main() {
    int counter = 1; // 1. Инициализация управляющей переменной

    while (counter <= 5) { // 2. Проверка условия
        printf("Шаг номер: %d\n", counter);
        counter = counter + 1; // 3. Обновление переменной (инкремент)
    }

    printf("Цикл завершен!\n");
    return 0;
}
```

### Смертельная опасность: бесконечный цикл
Если вы забудете обновить переменную внутри цикла (например, уберете строчку `counter = counter + 1;`), то условие `counter <= 5` всегда будет оставаться истинным (ведь `counter` навсегда останется равен `1`). 

Программа войдет в **бесконечный цикл**. Процессор будет на 100% загружен бессмысленным повторением вывода текста, программа зависнет, и вам придется принудительно завершать её через диспетчер задач или терминал. При написании любого цикла всегда проверяйте: **меняются ли переменные в теле цикла так, чтобы условие рано или поздно стало ложным?**

## Подглава 5.4: Цикл for — контролируемый обход и итераторы

Цикл `for` (в переводе — «для») идеально подходит для ситуаций, когда мы заранее точно знаем, сколько раз должен выполниться цикл (например, ровно 10 раз), или когда нам нужно последовательно обойти все элементы структуры данных в памяти (например, массива).

Цикл `for` объединяет в своей строке объявления три важнейших действия: **инициализацию**, **проверку условия** и **обновление** управляющей переменной (которую принято называть *итератором* и обозначать буквой `i`).

### Синтаксис цикла for:
```c
for (инициализация; условие; обновление) {
    // Тело цикла
}
```

### Жизненный цикл выполнения for:
1. **Инициализация:** Выполняется ровно **один раз** при первом входе в цикл. Здесь мы создаем переменную-счетчик и задаем ей стартовое значение (например, `int i = 0`).
2. **Проверка условия:** Проверяется перед каждым шагом цикла. Если оно истинно — выполняется тело цикла. Если ложно — цикл завершается.
3. **Выполнение тела цикла:** Выполняются инструкции в фигурных скобках.
4. **Обновление:** Выполняется **после** завершения тела цикла, но **до** следующей проверки условия. Здесь мы изменяем счетчик (например, увеличиваем его на единицу: `i = i + 1`).
5. Переход к шагу 2.

### Пример кода: классический счетчик
```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i = i + 1) {
        printf("Итерация: %d\n", i);
    }
    return 0;
}
```

### Использование цикла for для обхода массивов
В Лекции 4 мы узнали, что массив — это непрерывная последовательность ячеек памяти. Обходить массивы вручную поэлементно крайне неудобно. С помощью цикла `for` и переменной-итератора мы можем сделать это красиво и безопасно. 

Поскольку индексация массивов в Си начинается с нуля, наш итератор `i` будет выступать в роли индекса элемента массива.

```c
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50}; // Массив в непрерывной памяти

    // i меняется от 0 до 4 (всего 5 элементов)
    for (int i = 0; i < 5; i = i + 1) {
        printf("Элемент по индексу %d равен %d\n", i, numbers[i]);
    }

    return 0;
}
```
Сложность прохождения по такому массиву линейно зависит от количества элементов и составляет **O(n)**, где n — размер массива.

## Подглава 5.5: Управляющие операторы break и continue

Иногда логика программы требует вмешаться в стандартный ход работы цикла: досрочно прервать его выполнение или пропустить часть инструкций. Для этого в Си используются два ключевых слова: `break` и `continue`.

### 1. Оператор break — «выход из цикла»
Команда `break` мгновенно прекращает работу цикла, в котором она находится. Процессор сразу же выходит из цикла и переходит к коду, идущему после него.

**Пример использования:** Мы ищем определенное значение в массиве. Как только мы его нашли, продолжать поиск бессмысленно — мы прерываем цикл.

```c
#include <stdio.h>

int main() {
    int temperatures[5] = {18, 22, -5, 15, 20};
    
    for (int i = 0; i < 5; i = i + 1) {
        if (temperatures[i] < 0) {
            printf("Зафиксирован мороз по индексу %d: %d градусов!\n", i, temperatures[i]);
            break; // Немедленный выход из цикла, остальные элементы не проверяем
        }
    }
    
    printf("Проверка завершена.\n");
    return 0;
}
```

### 2. Оператор continue — «переход к следующему шагу»
Команда `continue` не прерывает цикл целиком, но заставляет процессор **пропустить все оставшиеся команды в теле текущей итерации** и немедленно прыгнуть к следующему шагу:
* В цикле `while` — процессор прыгает сразу на повторную **проверку условия**.
* В цикле `for` — процессор прыгает на фазу **обновления** переменной-итератора, а затем на проверку условия.

**Пример использования:** Нам нужно вывести на экран только положительные числа из массива, проигнорировав отрицательные.

```c
#include <stdio.h>

int main() {
    int measurements[5] = {12, -3, 15, -8, 10};

    for (int i = 0; i < 5; i = i + 1) {
        if (measurements[i] < 0) {
            continue; // Пропускаем отрицательное число, идем к следующей итерации
        }
        printf("Положительное измерение: %d\n", measurements[i]);
    }

    return 0;
}
```

## Практические задачи

### Задача 1: Сумматор массива
Напишите программу на Си, в которой:
1. Объявляется и инициализируется массив из 5 целых чисел (любые значения на ваш выбор).
2. С помощью цикла `for` вычисляется сумма всех элементов этого массива.
3. Итоговая сумма выводится на экран с поясняющим текстом.

### Задача 2: Поиск элемента (Линейный поиск)
Напишите программу на Си, которая:
1. Создает массив из 5 целых чисел.
2. С помощью цикла и условий ищет в этом массиве число `7`.
3. Если число найдено, программа должна вывести на экран сообщение с индексом этого элемента (например: «Число 7 найдено по индексу 2!») и немедленно прекратить дальнейший поиск.
4. Если числа `7` в массиве нет, программа должна вывести одно сообщение: «Число 7 в массиве не найдено». 
*Подсказка: используйте вспомогательную переменную-флаг, например `int found = 0;`, чтобы отследить, увенчался ли поиск успехом.*

### Задача 3: Теоретическая проверка (устно)
1. Представьте бесконечный цикл `while (1)`. Что физически происходит со счетчиком команд (регистром PC) процессора во время его выполнения? 
2. Представьте, что внутри цикла `for` вы написали оператор `continue`. Произойдет ли при этом обновление итератора (выполнение команды `i = i + 1`), или этот шаг будет пропущен вместе с остальным телом цикла? Объясните разницу в поведении `continue` для `for` и `while`.

## Подсказки к задачам

* **Подсказка к задаче 1:** Создайте переменную для накопления суммы (например, `int sum = 0;`) перед циклом. Внутри цикла `for` на каждой итерации прибавляйте текущий элемент массива к этой переменной: `sum = sum + numbers[i];`.
* **Подсказка к задаче 2:** Инициализируйте флаг `int found = 0;` перед циклом. Внутри цикла при совпадении текущего элемента с искомым числом, выведите сообщение, установите `found = 1` и выполните `break`. После завершения цикла проверьте значение флага: если `found` остался равен `0`, выведите сообщение о том, что число не найдено.
* **Подсказка к задаче 3:** Вспомните, как процессор осуществляет безусловные и условные переходы, манипулируя адресом в счетчике команд PC. Для второй части вопроса перечитайте подглаву 5.5, обратив внимание на фазу «Обновление» в жизненном цикле `for` по сравнению с простым условием в `while`.
