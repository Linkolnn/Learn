# Начало

"Помоги найти план обучения одного из IT университета. чтобы самостоятельно изучить темы. Темы должны быть про работу сети интернет а после перейти на тему веб разработки (фронтенд -> фуллстек)"

**Учебный план для самостоятельного изучения** основан на реальных программах бакалавриата по направлению «Информационные системы и технологии» ведущих IT-университетов (таких как **ИТМО, ВШЭ и МФТИ**). Этот трек построен по принципу «от низкого уровня к высокому»: сначала вы разберетесь, как передаются биты по проводам, а затем научитесь создавать полноценные веб-приложения.

## Блок 1: Архитектура сетей и интернет (Основы)

Этот этап необходим, чтобы понимать, что происходит, когда пользователь вводит адрес сайта в строку браузера.

- **Модель OSI и стек TCP/IP.** Понимание 7 уровней сетевой модели и реального 4-уровневого стека интернета.
- **Физический и канальный уровни.** Работа коммутаторов (switches), MAC-адреса, ARP-протокол.
- **Сетевой уровень (Network).** IP-адресация (IPv4, IPv6), подсети, маски, базовая маршрутизация и протоколы (OSPF, BGP).
- **Транспортный уровень.** Разница между надежным TCP (трехэтапное рукопожатие, контроль перегрузок) и быстрым UDP.
- **Прикладной уровень.** Работа протокола DNS (разрешение имен в IP), DHCP (автоматическое получение настроек сети).
- **Протоколы веб-передачи.** Глубокое изучение HTTP/HTTPS (методы GET/POST, коды ответов, заголовки, куки).
- **Инструменты.** Базовая работа в консоли (ping, traceroute, nslookup) и анализ сетевых пакетов в Wireshark.

Блок 2: Фронтенд-разработка (Frontend)

Переход к созданию визуальной и интерактивной части веб-сайтов, которая работает внутри браузера.

- **Верстка (HTML5 & CSS3).** Семантическая структура страницы, блочная модель (Box Model), флексы (Flexbox), сетки (Grid), адаптивность под мобильные устройства (Media Queries).
- **Базовый JavaScript (ES6+).** Синтаксис, типы данных, работа с DOM (управление элементами на странице), обработка событий (клики, ввод текста).
- **Асинхронный JavaScript.** Работа с API браузера, fetch, промисы (Promises), синтаксис async/await. На этом этапе вы соединяете Блок 1 с фронтендом, делая сетевые запросы к серверам.
- **Сборщики и инструменты.** Система контроля версий Git, работа с GitHub, пакетный менеджер npm, базовые сборщики (Vite или Webpack).
- **Фронтенд-фреймворк.** Изучение одного из популярных инструментов на выбор: React (рекомендуется как самый востребованный), Vue.js или Angular. Компонентный подход и управление состоянием.

Блок 3: Бэкенд и переход в Фуллстек (Backend & Fullstack)

Разработка серверной логики, которая обрабатывает запросы от фронтенда, сохраняет данные и обеспечивает безопасность.

- **Серверный язык и среда.** Изучение Node.js и фреймворка Express (для JS-разработчиков это самый быстрый путь в фуллстек). Альтернативы: Python (FastAPI/Django) или Go.
- **Проектирование API.** Архитектурный стиль REST API (правильные URL, статус-коды, JSON-формат для обмена данными), основы WebSocket для работы в реальном времени.
- **Базы данных (БД).** Реляционные БД (PostgreSQL или MySQL) и язык запросов SQL (таблицы, связи, индексы). Нереляционные БД (MongoDB) для хранения документов.
- **Авторизация и безопасность.** Механизмы сессий, работа с JWT (JSON Web Tokens), хеширование паролей (bcrypt), основы веб-безопасности (защита от CORS, XSS, CSRF атак).
- **Деплой и окружение.** Работа в терминале Linux, контейнеризация приложений с помощью Docker, оркестрация и развертывание проекта на облачный сервер (VPS).

## Анализ книг: Фило и Таненбаум

Обе книги **определенно помогут**, но у них абсолютно разные роли:

1. **«Теоретический минимум по Computer Science» (Владстон Феррейра Фило)**:
    - **Зачем нужна:** Это идеальный «разогрев» перед стартом. Автор без заумных академических терминов объясняет логику, основы алгоритмов, структуру данных и сложность \(O(n)\).
    - **Вердикт:** Прочитайте её **в первую же неделю** целиком. Она даст верхнеуровневую карту памяти для всего последующего обучения. [[Теоретический минимум по Computer Science.pdf]]
2. **«Компьютерные сети» (Эндрю Таненбаум)**:
    - **Зачем нужна:** Это фундаментальная «библия» IT-вузов. Она невероятно подробная и глубокая.
    - **Вердикт:** Использовать **как справочник**, а не для линейного чтения от корки до корки (иначе быстро выгорите). Возник вопрос по деталям работы TCP — открываете конкретную главу. [[1](https://www.scribd.com/presentation/717600230/CN-IOT-Module-1-Introduction-1)]

Детализированный план обучения (Месяцы 1–3)

План совмещает теорию сетей, низкоуровневое программирование на **C (Си)** для понимания алгоритмов и переход к веб-технологиям.

Месяц 1: Архитектура сетей и погружение в язык C

**Цель:** Понять, как пакеты ходят по сети, и освоить синтаксис C для работы с памятью.

- **Неделя 1: Модель OSI и стек TCP/IP**
    - _Теория:_ Разбор уровней: от физического провода до протокола HTTP.
    - _Практика:_ Установка анализатора трафика [Wireshark](https://www.wireshark.org/). Перехватите свой первый незашифрованный HTTP-пакет и посмотрите его заголовки.
    - _Источники:_ Плейлист «Компьютерные сети» Андрея Созыкина (Смотреть видео 1–10).
- **Неделя 2: IP-адресация и Маршрутизация**
    - _Теория:_ IPv4, маски подсетей (CIDR), NAT, работа DNS и DHCP.
    - _Практика:_ В консоли (терминале) вбейте команды `ping`, `traceroute` (или `tracert`) до сайта google.com. Разберитесь, через сколько узлов прошел ваш запрос.
    - _Источники:_ Статья «Как работает DNS» на MDN Web Docs.
- **Неделя 3: Основы языка C (Си)**
    - _Теория:_ Переменные, типы данных, циклы, функции и самое важное — **указатели** (работа с адресами памяти).
    - _Практика:_ Написать простую программу на Си, которая меняет значения двух переменных местами с помощью указателей.
    - _Источники:_ Легендарный курс [Гарвардского университета CS50 на русском](https://www.youtube.com/playlist?list=PLawfWYMUziZqyUL5QDLVbe3j5BKWj42E5) (Лекции 1, 2 и 3).
- **Неделя 4: Транспортный уровень и Сетевой код**
    - _Теория:_ Разница между TCP и UDP. Понятие сетевого порта.
    - _Практика:_ Попробуйте написать в коде Си простейший сетевой сокет (Socket), который умеет отправлять строку текста на локальный сервер.
    - _Источники:_ Документация [Beej's Guide to Network Programming](https://beej.us/guide/bgnet/) (лучший мировой гид по сокетам, можно использовать переводчик).

---

Месяц 2: Базовые алгоритмы и структуры данных (на языке C)

**Цель:** Изучить классические алгоритмы, вручную управляя памятью в Си, чтобы понять «подкапотный» контекст разработки.

- **Неделя 5: Сложность алгоритмов и Массивы**
    - _Теория:_ Нотация Big O (\(O(1), O(n), O(n^2)\)). Линейный и бинарный поиск.
    - _Практика:_ Написать бинарный поиск на Си. Измерить, во сколько раз он быстрее линейного поиска на массиве из 1 000 000 элементов.
    - _Источники:_ Глава «Алгоритмическая сложность» в книге Фило + интерактивные визуализации на [Visualgo.net](https://visualgo.net/ru). [[1](https://www.quora.com/When-you-should-study-these-5-subjects-Data-Structure-Algorithm-Computer-Networking-Database-OS-what-would-you-study-first), [2](https://medium.com/@ulises_lara_/book-review-computer-science-distilled-by-wladston-ferreira-8c18c3bd7592)]
- **Неделя 6: Алгоритмы сортировки**
    - _Теория:_ Сортировка пузырьком (Bubble), сортировка вставками (Insertion) и быстрая сортировка (QuickSort).
    - _Практика:_ Реализовать QuickSort на Си с использованием рекурсии.
    - _Источники:_ Раздел сортировок на [GeeksforGeeks C Programming](https://www.geeksforgeeks.org/c-programming-language/).
- **Неделя 7: Базовые структуры данных**
    - _Теория:_ Динамические структуры данных. Связанные списки (Linked Lists), Стек (Stack), Очередь (Queue).
    - _Практика:_ Создать структуру односвязного списка на Си, реализовать функции добавления и удаления узлов с помощью функций управления памятью `malloc()` и `free()`.
    - _Источники:_ [Лекция по структурам данных курса CS50](https://cs50.harvard.edu/x/2024/weeks/5/) (оригинальный сайт с заданиями). [[1](https://www.quora.com/When-you-should-study-these-5-subjects-Data-Structure-Algorithm-Computer-Networking-Database-OS-what-would-you-study-first)]
- **Неделя 8: Хеш-таблицы и Деревья**
    - _Теория:_ Понятие хэш-функции, коллизии. Бинарные деревья поиска (BST).
    - _Практика:_ Реализовать простейшее бинарное дерево на Си и функцию обхода этого дерева.
    - _Источники:_ Интерактивная карта [Roadmap.sh — Computer Science](https://roadmap.sh/computer-science). [[1](https://www.quora.com/When-you-should-study-these-5-subjects-Data-Structure-Algorithm-Computer-Networking-Database-OS-what-would-you-study-first)]

Месяц 3: Переход в Веб-разработку (Фронтенд-старт)

**Цель:** Перенести понимание сетей (HTTP/Интернета) на практику создания интерфейсов. Мы уходим от Си в сторону HTML, CSS и JavaScript.

- **Неделя 9: HTML5 и Основы веба**
    - _Теория:_ Как браузер запрашивает и парсит HTML. Семантические теги (`<header>`, `<main>`, `<article>`).
    - _Практика:_ Сверстать текстовую структуру вашей будущей страницы-портфолио (пока без стилей).
    - _Источники:_ Главный бесплатный учебник фронтендера [MDN Web Docs — Изучение HTML](https://developer.mozilla.org/ru/docs/Learn/HTML).
- **Неделя 10: CSS3 — Стилизация и Сетки**
    - _Теория:_ Каскадность, селекторы, Блочная модель (Box Model), современные сетки Flexbox.
    - _Практика:_ Оформить портфолио: сделать адаптивную шапку сайта и карточки проектов с помощью Flexbox.
    - _Источники:_ Тренажер [Спецификация CSS на Л things (CSS-Tricks)](https://css-tricks.com/) и интерактивная игра [Flexbox Froggy](https://flexboxfroggy.com/#ru).
- **Неделя 11: Основы JavaScript (Синтаксис)**
    - _Теория:_ Почему JS похож на Си (циклы `for`, условия `if-else`), но имеет динамическую типизацию. Переменные `let`, `const`, функции, объекты.
    - _Практика:_ Написать скрипт, который принимает массив чисел и находит в нем максимальное (алгоритмическая задача, перенесенная из месяца 2 на рельсы JavaScript).
    - _Источники:_ Главный русскоязычный учебник [Современный учебник JavaScript](https://learn.javascript.ru/).
- **Неделя 12: Связь Веба и Сетей (DOM и Fetch)**
    - _Теория:_ Что такое DOM-дерево. Как JS делает сетевые запросы. Протокол HTTP в действии через метод `fetch()`.
    - _Практика:_ Написать мини-приложение «Прогноз погоды»: фронтенд делает запрос через `fetch` на бесплатный сервер погоды (API) и выводит данные на вашу HTML-страницу.
    - _Источники:_ Раздел [«Сетевые запросы» на learn.javascript.ru](https://learn.javascript.ru/network).
